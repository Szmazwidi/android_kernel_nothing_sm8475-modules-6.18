# CLG277 source integration

This source checkout adds fifteen platform module outputs from Claude CLG3/CLG8
to the earlier QRTR256 cohort: total277 =193 vendor +84 GKI. The qualified
first-stage module inventory has100 entries, pinned in
`cohorts/CLG277-first-stage.modules`. PMU/DCVS are first-stage dependencies;
loading them later from vendor.modprobe fails perfmon capability checks.

Kernel source prerequisite: CLG1 commit
58b289d57b3d1f4b6fa6bb51db13920f459ae153, including the explicit
`//common:pong_lab_defconfig` fragment. The wrappers select this LAB profile;
they do not silently disable device write guards. The kernel/modules remote
pins for this integration must be published together before advertising a
self-contained new manifest. Existing older XML locks are preserved as history.

The top-level output graph and new reference explicitly name all193 vendor
outputs and84 GKI modules. The default wrappers use that reference and check
its declared counts and exact module names, rather than accepting a loose
minimum count. The old262 reference file remains unchanged for its old source
checkpoint. Never use a new graph with an old reference or an old262 prebuilt.

user data or raw device logs are included in this source update.
